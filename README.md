# Yunseo

**Building AI applications, from models to interfaces.**

AI 기능을 웹 서비스와 사용자 경험으로 연결하는 프로젝트를 만듭니다.
이곳에는 자연어 기반 생성 도구, AI와 함께 사용하는 서비스, 실시간 웹 애플리케이션을 기록합니다.

## Selected projects

### [Open Roadmap](https://github.com/Yunseo-Lab/open-roadmap)
AI와 함께 로드맵을 만들고, 목표와 활동의 근거를 공개 포트폴리오로 연결하는 웹 애플리케이션입니다.

`React` · `TypeScript` · `Hono` · `Cloudflare Workers` · `Python`

### [SayItSeeIt](https://github.com/Yunseo-Lab/SayItSeeIt)
자연어 요청과 이미지로 카드뉴스 레이아웃을 생성하는 프로젝트입니다. LayoutPrompter를 기반으로 생성 파이프라인을 구성하고, FastAPI와 Flutter 웹 UI를 연결합니다.

`Python` · `FastAPI` · `Flutter` · `LLM`

### [Agent Arena](https://github.com/Yunseo-Lab/agent-arena)
좌표와 API로 대국할 수 있는 실시간 오목 웹앱입니다. WebSocket 상태 동기화와 게임 규칙 엔진을 구현하고, AI 에이전트 연동을 위한 구조화된 인터페이스를 제공합니다.

`Next.js` · `TypeScript` · `Node.js` · `WebSocket`
