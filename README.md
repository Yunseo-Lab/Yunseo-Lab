# Yunseo

I'm interested in multimodal retrieval and AI agents.
I build systems that help people find, understand, and work with information.

Selected work:

- [Video Scene Search](https://github.com/boostcampaitech7/level4-nlp-finalproject-hackathon-nlp-01-lv3) — A team project for natural-language video retrieval. My contributions included multimodal embeddings, Rank Fusion retrieval, and application interfaces.
- [Open Roadmap](https://github.com/Yunseo-Lab/open-roadmap) — An AI-assisted roadmap editor connecting goals, progress, and evidence.
- [SayItSeeIt](https://github.com/Yunseo-Lab/SayItSeeIt) — Promotional visual generation from text and images, built on LayoutPrompter.
